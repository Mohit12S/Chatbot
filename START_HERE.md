## Quick Command Reference

```bash
# Backend Setup & Run
cd backend
python -m venv venv
venv\Scripts\activate  # Windows only
pip install -r requirements.txt
# Edit .env with your credentials
python app.py

# Frontend Setup & Run
cd frontend
npm install
npm run dev

# Then visit: http://localhost:5173
```

## What Happens When You Run It

```
1. Browser → Frontend (React at localhost:5173)
   ↓
2. User types message
   ↓
3. Frontend → Backend (FastAPI at localhost:8000)
   ↓
4. Backend → Hugging Face (AI response)
   ↓
5. Backend → Firebase (save conversation)
   ↓
6. Frontend ← Response back to user
   ↓
7. Chat displays AI answer
   ↓
8. Firebase has permanent record
```

All automated and production-ready!
